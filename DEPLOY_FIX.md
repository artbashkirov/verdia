# Решение проблемы с деплоем

GitHub Actions выполнился успешно, но изменения не видны в проде. Это может быть связано с тем, что на VPS не применились изменения или нужно очистить кэш.

## Быстрое решение

### Вариант 1: Принудительный деплой через скрипт (рекомендуется)

Выполните на вашем компьютере:

```bash
ssh root@193.227.240.206 'bash -s' < scripts/force-deploy-vps.sh
```

Этот скрипт:
1. Обновит код на VPS
2. Очистит кэш Next.js
3. Пересоберет приложение
4. Перезапустит PM2

### Вариант 2: Ручной деплой через SSH

Подключитесь к VPS и выполните вручную:

```bash
ssh root@193.227.240.206
cd /opt/verdia-app

# Обновляем код
git fetch origin
git reset --hard origin/main

# Устанавливаем зависимости
npm install --production=false

# Очищаем кэш
rm -rf .next
rm -rf node_modules/.cache

# Собираем
npm run build

# Перезапускаем
pm2 restart verdia --update-env
pm2 save

# Проверяем статус
pm2 list
pm2 logs verdia --lines 30 --nostream
```

### Вариант 3: Проверка текущего состояния

Сначала проверьте, что на VPS:

```bash
ssh root@193.227.240.206
cd /opt/verdia-app

# Проверьте текущий коммит
git log -1 --oneline

# Должен быть коммит 526ce7e или новее
# Если нет - выполните деплой из Варианта 2

# Проверьте, что PM2 работает
pm2 list

# Проверьте логи
pm2 logs verdia --lines 50 --nostream
```

## После деплоя

1. **Очистите кэш браузера:**
   - Откройте сайт в режиме инкогнито
   - Нажмите Ctrl+Shift+R (или Cmd+Shift+R на Mac) для жесткой перезагрузки
   - Или откройте DevTools → Network → включите "Disable cache"

2. **Проверьте изменения:**
   - Должна быть кнопка "Подробнее" рядом с вероятностью
   - Новые изменения в интерфейсе

## Возможные проблемы

### Проблема: Старый код на VPS
**Решение:** Выполните `git reset --hard origin/main` на VPS

### Проблема: Кэш Next.js
**Решение:** Удалите `.next` директорию и пересоберите

### Проблема: PM2 не перезапустился
**Решение:** Выполните `pm2 restart verdia --update-env`

### Проблема: Кэш браузера
**Решение:** Используйте режим инкогнито и жесткую перезагрузку
