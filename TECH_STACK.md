# Технологический стек проекта Verdia

## 🎯 Обзор

Verdia — это веб-приложение для подготовки юридических документов с использованием AI, построенное на современном стеке технологий.

---

## 🖥 Frontend

### Основной фреймворк
- **Next.js 16.0.5** — React-фреймворк с App Router
  - Server-Side Rendering (SSR)
  - Server Components
  - API Routes
  - Оптимизация изображений (AVIF, WebP)

### UI библиотеки
- **React 19.2.0** — библиотека для построения пользовательского интерфейса
- **React DOM 19.2.0** — рендеринг React компонентов

### Стилизация
- **Tailwind CSS 4** — utility-first CSS фреймворк
- **@tailwindcss/postcss 4** — PostCSS плагин для Tailwind
- **Lightning CSS 1.30.2** — быстрый CSS парсер и минификатор
  - `lightningcss-darwin-arm64` — нативная сборка для macOS ARM

### Иконки
- **Lucide React 0.562.0** — библиотека иконок

---

## 🔧 Backend & API

### Серверная часть
- **Next.js API Routes** — встроенные API эндпоинты
  - `/api/chat` — обработка чат-запросов
  - `/api/generate` — генерация документов
  - `/api/search` — поиск судебной практики

### База данных
- **Supabase** — Backend-as-a-Service
  - **PostgreSQL** — реляционная база данных
  - **@supabase/supabase-js 2.86.0** — JavaScript клиент
  - **@supabase/ssr 0.8.0** — поддержка Server-Side Rendering
  - Аутентификация и авторизация
  - Row Level Security (RLS)

## 🔄 Потоки данных

### Обработка запросов пользователя
1. Пользователь отправляет запрос через UI
2. Next.js API Route получает запрос
3. OpenAI генерирует поисковый запрос (GPT-4o-mini)
4. Puppeteer парсит sudact.ru для поиска релевантных дел
5. OpenAI генерирует юридический ответ с контекстом (GPT-4o)
6. Ответ сохраняется в Supabase
7. Пользователь получает структурированный ответ

### Генерация документов
1. Пользователь запрашивает экспорт документа
2. Контент форматируется через `docx` библиотеку
3. Файл генерируется на сервере
4. Файл скачивается через `file-saver`
