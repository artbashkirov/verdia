## Быстрый старт (справочно)

### Способ 1: Деплой через веб-интерфейс Vercel (самый простой способ) ⭐

1. **Перейдите на [vercel.com](https://vercel.com)** и войдите через GitHub
2. **Нажмите "Add New Project"**
3. **Выберите репозиторий** `verdia` из списка GitHub репозиториев
4. **Настройте проект:**
   - Framework Preset: **Next.js** (определится автоматически)
   - Root Directory: `./` (оставьте по умолчанию)
   - Build Command: `npm run build` (по умолчанию)
   - Output Directory: `.next` (по умолчанию)
   - Install Command: `npm install` (по умолчанию)
5. **Добавьте переменные окружения** (см. раздел ниже)
6. **Нажмите "Deploy"**

После деплоя Vercel автоматически будет деплоить каждое изменение в ветке `main`.

### Способ 2: Использование npx (не требует установки)

1. **Авторизуйтесь в Vercel**:
   ```bash
   npx vercel login
   ```

2. **Задеплойте проект**:
   ```bash
   npx vercel
   ```
   При первом деплое следуйте инструкциям в терминале.

3. **Для продакшн деплоя**:
   ```bash
   npx vercel --prod
   ```

### Способ 2: Локальная установка в проект

1. **Установите Vercel CLI локально**:
   ```bash
   npm install -D vercel
   ```

2. **Используйте через npx**:
   ```bash
   npx vercel login
   npx vercel
   ```

### Способ 3: Глобальная установка (требует прав администратора)

Если вы хотите установить глобально:

**macOS/Linux:**
```bash
sudo npm i -g vercel
```

**Или настройте npm для установки без sudo:**
```bash
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc
npm i -g vercel
```

## ⚠️ Важно: Проблемы с npm

Если у вас возникают ошибки `EPERM` или `EACCES` при работе с npm (особенно если проект в iCloud Drive), рекомендуется использовать **Способ 1 (веб-интерфейс)** - это самый простой и надежный метод деплоя.

## Настройка переменных окружения на Vercel

После первого деплоя необходимо настроить переменные окружения в панели Vercel. Это **критически важно** для работы приложения.

### Пошаговая инструкция:

1. **Войдите на [vercel.com](https://vercel.com)** и авторизуйтесь через GitHub

2. **Найдите ваш проект:**
   - В главном дашборде найдите проект `verdia`
   - Или перейдите по прямой ссылке: `https://vercel.com/dashboard` → выберите проект

3. **Откройте настройки проекта:**
   - В верхнем меню проекта нажмите на вкладку **"Settings"**
   - В левом боковом меню выберите **"Environment Variables"**

4. **Добавьте переменные окружения:**

   Для каждой переменной выполните следующие шаги:

   **Переменная 1: NEXT_PUBLIC_SUPABASE_URL**
   - В поле **"Key"** введите: `NEXT_PUBLIC_SUPABASE_URL`
   - В поле **"Value"** введите ваш Supabase URL (например: `https://xxxxx.supabase.co`)
   - Выберите окружения: ✅ **Production**, ✅ **Preview**, ✅ **Development**
   - Нажмите **"Save"**

   **Переменная 2: NEXT_PUBLIC_SUPABASE_ANON_KEY**
   - В поле **"Key"** введите: `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - В поле **"Value"** введите ваш Supabase Anon Key (публичный ключ)
   - Выберите окружения: ✅ **Production**, ✅ **Preview**, ✅ **Development**
   - Нажмите **"Save"**

   **Переменная 3: OPENAI_API_KEY**
   - В поле **"Key"** введите: `OPENAI_API_KEY`
   - В поле **"Value"** введите ключи для AI: для Gemini — CLOUDFLARE_WORKER_URL и CLOUDFLARE_WORKER_SECRET; для OpenAI (опционально) — OPENAI_API_KEY
   - Выберите окружения: ✅ **Production**, ✅ **Preview**, ✅ **Development**
   - Нажмите **"Save"**

5. **Где найти значения переменных:**

   **Supabase URL и Anon Key:**
   - Перейдите на [supabase.com/dashboard](https://supabase.com/dashboard)
   - Выберите ваш проект
   - Перейдите в **Settings** (шестеренка внизу слева) → **API**
   - Скопируйте:
     - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`
     - **anon/public key** → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`

   **AI (основная — Gemini):** CLOUDFLARE_WORKER_URL, CLOUDFLARE_WORKER_SECRET. **OpenAI (опционально):** [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
   - Войдите в аккаунт
   - Создайте новый ключ или используйте существующий
   - Скопируйте ключ (он начинается с `sk-`)

6. **После добавления всех переменных:**
   - Перейдите в **Deployments** в верхнем меню
   - Найдите последний деплой и нажмите на три точки (⋯) справа
   - Выберите **"Redeploy"** для применения новых переменных
   - Или просто сделайте новый push в GitHub - Vercel автоматически задеплоит с новыми переменными

### ⚠️ Важные моменты:

- ✅ **Всегда добавляйте переменные для всех трех окружений** (Production, Preview, Development)
- ✅ **Без этих переменных приложение не будет работать** - Supabase не подключится, AI не будет работать
- ✅ **Значения переменных скрыты** - они не видны в коде и безопасны
- ✅ **После изменения переменных нужно передеплоить** проект

### 📋 Чек-лист переменных:

Убедитесь, что добавлены все три переменные:
- [ ] `NEXT_PUBLIC_SUPABASE_URL` - для всех окружений
- [ ] `NEXT_PUBLIC_SUPABASE_ANON_KEY` - для всех окружений  
- [ ] `OPENAI_API_KEY` - для всех окружений

### 🔄 Если переменные не работают:

1. Проверьте, что переменные добавлены для нужного окружения (Production/Preview)
2. Убедитесь, что после добавления переменных вы сделали redeploy
3. Проверьте логи деплоя в Vercel Dashboard → Deployments → выберите деплой → Functions
4. Убедитесь, что названия переменных точно совпадают (чувствительны к регистру!)

## Настройка домена

1. В панели Vercel перейдите в **Settings** → **Domains**
2. Добавьте ваш домен
3. Следуйте инструкциям для настройки DNS записей

Обычно нужно добавить CNAME запись:
```
Type: CNAME
Name: @ или www
Value: cname.vercel-dns.com
```

Или A запись для apex домена:
```
Type: A
Name: @
Value: 76.76.21.21
```

## Особенности проекта

### Puppeteer на Vercel

Проект использует `puppeteer-core` для парсинга судебных решений. На Vercel это работает через serverless функции, но:

- ⚠️ Функции имеют ограничение по времени выполнения (до 60 секунд на Pro плане)
- ⚠️ Требуется дополнительная память для работы Chrome headless
- 💡 Рекомендуется использовать альтернативные методы парсинга для production

Для оптимизации на Vercel можно:
1. Использовать Vercel Edge Functions для простых запросов
2. Использовать внешний сервис парсинга через API
3. Настроить отдельный worker для тяжелых операций

### Оптимизация

Проект настроен с:
- ✅ Standalone output для быстрой загрузки
- ✅ SWC minification для оптимизации кода
- ✅ Image optimization через Next.js Image
- ✅ Security headers

## Мониторинг и логи

## Troubleshooting

### Ошибка сборки
- Проверьте, что все переменные окружения установлены
- Проверьте логи сборки в панели Vercel

### Ошибки Supabase
- Убедитесь, что `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY` правильно установлены
- Проверьте настройки CORS в Supabase Dashboard

### Проблемы с Puppeteer
- На Vercel Puppeteer требует дополнительной конфигурации
- Рассмотрите использование альтернативных методов парсинга
